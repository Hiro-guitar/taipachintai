# キーワード調査（2026年10月）

Google キーワードプランナーの実数。対象は日本、期間は2025年9月〜2026年8月。
種キーワード6語から753件の候補が出たうち、タイパ賃貸に関係するものを抜き出した。
検索数は、広告を運用していないアカウントのため区切りのよい概数で出る（50／500／5,000／50,000）。

「競合性」は**広告の競合性**であって、SEOの難易度ではない。検索数が大きい語ほど、
SEOでは大手ポータルが上位を固めていると考えたほうがよい。

---

## 結論

| | 月間検索数 | 判断 |
|---|---|---|
| 先行申込 系（18語の合計） | 約4,650 | **SEOで取りに行く**。競合性すべて低、大手が力を入れていない |
| オンライン内見 系（合計） | 約3,200 | **SEOで取りに行く**。同上 |
| 仲介手数料の仕組み・疑問 | 1語で5,000規模 | **記事で取りに行く**。「からくり」「おかしい」は読者が疑っている状態 |
| 仲介手数料0円・無料 | 5,000規模 | 検索数は大きいが手数料無料の専門業者がひしめく。**広告向き** |
| 上京・遠方 部屋探し | 各50 | **小さすぎる**。1位でも流入が出ない |

既存3記事が狙っているのは最下段の語。記事の質ではなく、的が小さい。
