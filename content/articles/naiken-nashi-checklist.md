進学や就職、転職や転勤で上京するときは、部屋を見に行く時間も交通費もかけられないことがあります。進学先や勤務先が決まってから入居までが2週間ほどしかなく、現地に行く余裕がないというケースも珍しくありません。

確認すべき点を押さえておけば、内見をしなくても大きな失敗は防げます。ただし、すべての部屋が内見なしで申し込めるわけではありません。この記事では、確認したい項目をチェックリストの形で整理したうえで、内見なしで申し込める部屋とそうでない部屋の違いも説明します。

## 内見なしで決める人は、実は珍しくない

賃貸借契約は、2017年から重要事項説明をビデオ通話で受けられるようになり、2022年には契約書の電子化も認められました。現地に一度も足を運ばずに、申込から契約までを終えることが制度上は可能です。実際には契約書を郵送でやり取りすることが多いものの、来店する必要はありません。

人気のエリアや繁忙期（1〜3月）には、内見の予定を組んでいる間に他の人に申し込まれてしまうことがあります。見てから決めるよりも、決めてから確認するほうが、条件のよい部屋を押さえやすい場面もあります。

## 内見なしでも分かること、分からないこと

内見をするかどうかを判断する前に、何が分かって何が分からないのかを整理しておきます。

| 内見しなくても確認できる | 現地でないと分かりにくい |
|---|---|
| 間取り・広さ・収納の大きさ | におい |
| 設備（エアコン、コンロ、洗濯機置き場など） | 周りの音の感じ方 |
| 日当たりの向き | 日当たりの体感 |
| 駅やスーパーまでの距離 | 建物の雰囲気・住人の様子 |
| 災害リスク（浸水・土砂災害） | 部屋の細かい汚れや傷 |
| 家賃が相場と比べて妥当か | |

右側の項目がどうしても気になる場合は、無理に内見なしで進めないほうがよいでしょう。左側の項目で判断できるのであれば、内見なしは時間と交通費の節約になります。

## 内見なしで申し込める部屋と、そうでない部屋

内見なしで申し込めるかどうかは、**その部屋にまだ人が住んでいるかどうか**で決まります。

- **退去前（まだ人が住んでいる）**：居住中のため内見ができず、申込が先になります。申込で順番を確保し、退去後に内見してから契約する形が一般的です。これを先行申込と呼びます
- **退去済み（空室）**：いつでも内見できる状態のため、管理会社から「内見をしてから申し込んでほしい」と言われることが多くなります。内見なしの申込に対応する物件もありますが、管理会社の方針によります

内見なしで進めやすいのは退去前の部屋です。空室でも申込が通ることはありますが、管理会社に確認するまでは分かりません。気になる部屋が見つかったら、まずその部屋が内見なしで申し込めるかどうかを調べておくと確実です。

## チェックリスト1：部屋そのもの

### 間取り図で広さと配置を確認する

- **洋室の帖数**：1帖はおよそ1.6㎡で、6帖なら10㎡弱です。ベッド・机・収納を置いたときに、通る場所が残るかを想像してみてください
- **収納の位置と大きさ**：クローゼットか、押入れか
- **洗濯機置き場**：室内か、ベランダ（屋外）か
- **冷蔵庫置き場**：キッチンの横に置けるスペースがあるか

間取り図から読み取れるのは部屋の配置までで、壁の長さや置き場の寸法までは分かりません。帖数が記載されていない図面もあり、その場合は募集ページの専有面積が目安になります。

冷蔵庫や洗濯機は、入居してから採寸して購入するのがもっとも確実です。いま使っているものを運ぶ場合は、搬入できない可能性が残ることを前提に考えておきましょう。

### 写真で確認するポイント

掲載写真は、部屋がもっともきれいに見える角度で撮影されています。次の3点に注目してください。

- **写っていない場所**：浴室やトイレの写真が載っていない物件もあります
- **窓の外**：隣の建物との距離が写っているか
- **コンロの種類**：ガスかIHか、1口か2口か

居住中の部屋では新たに撮影できないため、追加してもらえるとすれば前回募集時の写真や動画です。掲載されている写真だけで判断できるかどうかを基準に考えておくのが現実的です。

なお、掲載されている写真や設備の情報は、前回募集時のものが使われている場合があります。契約時は現況が優先されるため、洗濯機置き場が室内であること、コンロが2口であることなど、外せない条件は申込前に確認してください。

## チェックリスト2：建物と周辺環境

### 構造・耐震・部屋の位置

- **構造**：鉄筋コンクリート（RC）造は、木造や軽量鉄骨造に比べて上下左右の音が伝わりにくい傾向があります
- **築年数（耐震基準）**：1981年6月以降に建築確認を受けた建物は、現在の耐震基準（新耐震）で建てられています。1983年以降に完成した建物であれば、ほぼ該当します。1981〜1982年完成の建物は建築確認の時期によって変わるため、気になる場合は確認しておきましょう
- **部屋の位置**：1階は防犯面や湿気が気になるという人もいます。角部屋や最上階は、隣や上の階からの音が減ります
- **リフォームの有無**：「内装リフォーム済」の記載があれば、築年数が古くても設備が新しい場合があります

### 地図で周辺を確認する

Googleマップのストリートビューを使えば、駅から部屋までの道のりを画面上でたどれます。

- 駅からの道に、坂や階段がないか（荷物を持って歩く前提で見てください）
- 近くに線路や大きな道路がないか（音の目安になります）
- スーパー、コンビニ、ドラッグストアの場所

### 災害リスクを確認する

国土交通省の「[重ねるハザードマップ](https://disaportal.gsi.go.jp/)」に住所を入力すると、浸水や土砂災害の想定区域を確認できます。

ここで見るべきなのは、浸水するかどうかではなく**想定浸水深**です。大きな川の流域には3〜5m以上を想定している場所があり、そうした地域では2階も浸水します。建物ごと流される恐れがある「家屋倒壊等氾濫想定区域」に該当していないかも、あわせて確認してください。

水害リスクは2020年8月から重要事項説明の対象となっているため、契約前に必ず説明があります。

## チェックリスト3：お金と契約条件

### 初期費用の内訳を確認する

見積もりを受け取ったら、項目を一つずつ確認しましょう。

- **前家賃・日割り家賃**：契約時に、入居する月の日割り家賃と翌月分の家賃（前家賃）をまとめて支払うのが一般的です。家賃が発生する日を月末に近づけると日割り分は減りますが、そのぶん入居できる日も遅くなります
- **敷金**：大家さんに預けるお金です。退去時に、原状回復にかかった費用を差し引いて返還されます。敷金なしの物件は、代わりに退去時のクリーニング代が定額で設定されていることが多くなります
- **礼金**：大家さんに渡すお金で、返還されません
- **仲介手数料**：不動産会社に支払うお金です。上限は家賃1ヶ月分＋税と定められており、1ヶ月分を請求されるのが一般的です。ほかの項目と違い、どの会社に依頼するかで金額が変わります
- **保証会社の費用**：初回に総賃料（家賃＋共益費）の50%前後かかることが多く、さらに年1回、1万円前後の更新料が発生します
- **火災保険**：2年で1〜2万円ほどです。管理会社が指定する場合もあれば、自分で選べる場合もあります。選べるのであれば、同じ補償内容でより安いものが見つかることがあります
- **鍵交換**：1〜2万円ほどです。物件によっては、交換しないことを選べます
- **その他のオプション**：「消毒料」「安心サポート」などは、任意で外せる場合があります
- **入居後にかかるお金**：更新料（2年ごとに家賃1ヶ月分など）と、退去時のクリーニング代です。初期費用の見積もりには出てこないため見落としやすいものの、契約書には記載されています

### 契約の種類

- **普通借家契約**：更新しながら住み続けられる、一般的な契約です
- **定期借家契約**：期間が満了すると終了する契約です。再契約できるタイプもありますが、必ず再契約できるとは限りません。長く住むつもりであれば、再契約の条件まで確認しておきましょう

### 短期解約の違約金

「1年未満の解約は家賃1ヶ月分」といった条件が設定されている物件があります。早い時期に住み替える可能性がある場合は、必ず確認しておきたい項目です。

## 「先行申込」なら、申込のあとに内見できる

居住中の部屋では、**申込で順番を確保しておき、退去後に内見してから契約する**という進め方ができます。人気の部屋を押さえたうえで現地を確認してから判断できるため、内見なしに抵抗がある人にも向いています。

ただし、管理会社によっては内見の前に契約手続きへ進むよう求められる物件もあるため、申込前に確認してください。

申込をした時点では、まだ入居が決まったわけではありません。入居審査に数日かかり、通過して初めて契約に進みます。

**申込のキャンセルは、契約を結ぶ前であれば可能です**。申込は「この部屋を借りたい」という意思表示であり、契約とは別のものだからです。ただし、審査に通過したあとや初期費用を入金したあとは管理会社との調整が必要になるため、取りやめる可能性が出た時点で早めに伝えておくとスムーズです。

## まとめ：内見なしで決める前の最終チェック

- [ ] その部屋が内見なしで申し込めるかを確認した
- [ ] 大型家電をどうするか（入居後に買うか、運ぶか）決めた
- [ ] ストリートビューで駅からの道を確認した
- [ ] ハザードマップで想定浸水深を確認した
- [ ] 初期費用の内訳と、入居後にかかるお金を確認した
- [ ] 契約の種類と、短期解約の条件を確認した

以上の6点を押さえておけば、「住んでみたら想像と違った」という失敗は防ぎやすくなります。

ただし、におい、音の感じ方、建物の雰囲気は、現地でなければ分かりません。この点が気になる場合は、内見をしてから決めることをおすすめします。
