内示が出たのが3月の中ごろで、入居は4月1日。内見に行く週末がもうない。上京や転勤では、よくある話です。

見るところを押さえれば、内見なしでも大きな失敗は防げます。ただし、どの部屋でも内見なしで申し込めるわけではありません。

## 内見なしで決める人は、実は珍しくない

賃貸の契約は、2017年から重要事項説明をビデオ通話で受けられるようになり、2022年には契約書の電子化も認められました。現地に一度も行かずに、申込から契約まで終えられます。実際は契約書を郵送でやり取りすることが多いですが、お店に行かずにすみます。

人気のエリアや繁忙期（1〜3月）は、内見の予定を組んでいる間に他の人に申し込まれます。見てから決めるより、決めてから確かめるほうが、いい部屋を取りやすい。そういう場面もあります。

## 内見なしでも分かること、分からないこと

最初に、何が分かって何が分からないかを整理しておきます。

| 内見しなくても確認できる | 現地でないと分かりにくい |
|---|---|
| 間取り・広さ・収納の大きさ | におい |
| 設備（エアコン、コンロ、洗濯機置き場など） | 周りの音の感じ方 |
| 日当たりの向き | 日当たりの体感 |
| 駅やスーパーまでの距離 | 建物の雰囲気・住人の様子 |
| 災害リスク（浸水・土砂災害） | 部屋の細かい汚れや傷 |
| 家賃が相場と比べて妥当か | |

右の項目がどうしても気になるなら、無理に内見なしにしないほうがいいです。左の項目で判断できる人には、内見なしは時間とお金の節約になります。

## 内見なしで申し込める部屋と、そうでない部屋

**内見なしで申し込めるかどうかは、その部屋にまだ人が住んでいるかどうかで決まります**。

- **退去前（まだ人が住んでいる）**：そもそも内見ができないので、申込が先になります。申込で順番を確保して、退去後に内見してから契約する形が多いです。これを先行申込といいます
- **退去済み（空室）**：いつでも内見できる状態なので、管理会社から「内見してから申し込んでください」と言われることが多いです。内見なしの申込を受けてくれる部屋もありますが、管理会社によります

内見なしで進めやすいのは、退去前の部屋です。空室でも通ることはありますが、管理会社に聞くまで分かりません。

気になる部屋が見つかったら、申し込めるかどうかを先に調べてください。

## チェックリスト1：部屋そのもの

### 間取り図で広さと配置を見る

- **洋室の帖数**：1帖はおよそ1.6㎡。6帖なら10㎡弱です。ベッド・机・収納を置いて、通る場所が残るか想像してみてください
- **収納の位置と大きさ**：クローゼットか、押入れか
- **洗濯機置き場**：室内か、ベランダ（屋外）か
- **冷蔵庫置き場**：キッチンの横に置けるか

間取り図から読み取れるのは部屋の配置までで、壁の長さや置き場の寸法は分かりません。帖数が書かれていない図面もあり、そのときは募集ページの専有面積が目安になります。

冷蔵庫や洗濯機は、入居してから採寸して買うのがいちばん確実です。いま使っているものを運ぶなら、搬入できないことはあると思っておいてください。

### 写真で見るポイント

掲載写真は、部屋がいちばんきれいに見える角度で撮られています。見るところは3つです。

- **写っていない場所**：浴室やトイレの写真が載っていない部屋もあります
- **窓の外**：隣の建物との距離が写っているか
- **コンロの種類**：ガスかIHか、1口か2口か

まだ人が住んでいる部屋では、新しく写真を撮ってもらえません。増やしてもらえるとすれば、前回募集したときの写真や動画です。

掲載されている写真だけで判断できるか。そこが分かれ目です。

写真や設備の情報が、前回募集したときのままになっていることもあります。契約のときは現況が優先されます。洗濯機置き場が室内、コンロが2口。こういう外せない条件は、申し込む前に聞いておいてください。

## チェックリスト2：建物と周辺環境

### 構造・耐震・部屋の位置

- **構造**：鉄筋コンクリート（RC）造は、木造や軽量鉄骨造にくらべて、上下左右の音が伝わりにくいです
- **築年数（耐震基準）**：1981年6月以降に建築確認を受けた建物は、いまの耐震基準（新耐震）です。1983年以降にできた建物なら、まずあてはまります。1981〜1982年にできた建物は、建築確認がいつ下りたかで変わります
- **部屋の位置**：1階は防犯面や湿気が気になる人も。角部屋や最上階は、隣や上からの音が減ります
- **リフォームの有無**：「内装リフォーム済」とあれば、築年数が古くても設備が新しいことがあります

### 地図で周辺を歩いてみる

Googleマップのストリートビューを使えば、駅から部屋までの道を画面の上で歩けます。

- 駅からの道に、坂や階段がないか（荷物を持って歩く前提で見てください）
- 近くに線路や大きな道路がないか（音の目安になります）
- スーパー、コンビニ、ドラッグストアの場所

### 災害リスクを調べる

国土交通省の「[重ねるハザードマップ](https://disaportal.gsi.go.jp/)」に住所を入れると、浸水や土砂災害の想定区域が出ます。

見るのは、浸水するかどうかではありません。**想定浸水深**です。大きな川の近くには3〜5m以上を想定している場所があり、そこでは2階も水に浸かります。建物ごと流される恐れがある「家屋倒壊等氾濫想定区域」に入っていないかも、あわせて見てください。

水害リスクは2020年8月から重要事項説明の対象なので、契約の前に必ず説明があります。

## チェックリスト3：お金と契約条件

### 初期費用の内訳を見る

見積もりをもらったら、一つずつ項目を見てください。

- **前家賃・日割り家賃**：契約のときに、入居する月の日割り家賃と、翌月分の家賃（前家賃）をまとめて払います。家賃が発生する日を月末に近づけると日割り分は減りますが、そのぶん入居できる日も遅くなります
- **敷金**：大家さんに預けるお金です。退去のときに、原状回復にかかった費用を差し引いて返ってきます。敷金なしの部屋は、代わりに退去時のクリーニング代が定額で決められていることが多いです
- **礼金**：大家さんに渡すお金で、返ってきません
- **仲介手数料**：不動産会社に払うお金です。上限は家賃1ヶ月分＋税で、1ヶ月分を請求されることがほとんどです。ほかの項目とちがい、どの会社に頼むかで金額が変わります
- **保証会社の費用**：初回に総賃料（家賃＋共益費）の50%前後。さらに年1回、1万円前後の更新料がかかります
- **火災保険**：2年で1〜2万円ほど。管理会社が指定することもあれば、自分で選べることもあります。選べるなら、同じ補償でもっと安いものが見つかります
- **鍵交換**：1〜2万円ほど。部屋によっては、交換しないことを選べます
- **その他のオプション**：「消毒料」「安心サポート」などは、任意で外せることがあります
- **入居後にかかるお金**：更新料（2年ごとに家賃1ヶ月分など）、退去時のクリーニング代。初期費用には出てこないので見落としますが、契約書に書かれています

### 契約の種類

- **普通借家契約**：更新しながら住み続けられる、一般的な契約
- **定期借家契約**：期間が満了すると終わる契約。再契約できるタイプもありますが、必ずできるとは限りません。長く住むつもりなら、再契約の条件まで見ておいてください

### 短期解約の違約金

「1年未満の解約は家賃1ヶ月分」といった条件が付いている部屋があります。すぐに住み替える可能性があるなら、ここは見ておいてください。

## 「先行申込」なら、申込のあとに内見できる

まだ前の人が住んでいる部屋では、**申込で順番を確保しておき、退去後に内見してから契約する**という進め方ができます。人気の部屋を押さえたうえで現地を見てから決められるので、内見なしに抵抗がある人にも向いています。

ただし、内見の前に契約手続きへ進むよう求められる部屋もあるので、申し込む前に聞いておいてください。

申し込んだ時点では、まだ入居は決まっていません。入居審査に数日かかり、通って初めて契約に進めます。

**申込のキャンセルは、契約を結ぶ前であればできます**。申込は「この部屋を借りたい」という意思表示で、契約とは別のものだからです。ただし審査に通ったあとや、初期費用を入金したあとは、管理会社との調整が要ります。やめる可能性が出たら、早めに伝えてください。

## まとめ：内見なしで決める前の最終チェック

- [ ] その部屋が内見なしで申し込めるか調べた
- [ ] 大型家電をどうするか（入居後に買うか、運ぶか）決めた
- [ ] ストリートビューで駅からの道を見た
- [ ] ハザードマップで想定浸水深を見た
- [ ] 初期費用の内訳と、入居後にかかるお金を見た
- [ ] 契約の種類と、短期解約の条件を見た

この6つを押さえておけば、「住んでみたら全然違った」という失敗は防げます。

におい、音の感じ方、建物の雰囲気。ここは現地でなければ分からないので、気になるなら内見してから決めてください。
